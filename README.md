# 球団編成室 v2.0 — 「ぼくのプロ野球」非公式編成管理

**作成日：2026-10-22**　|　**対象：iPhone・PCブラウザ**　|　**動作形式：単独で動作する静的Webアプリ**

本家ゲームと連携するものではありません。ご自身のスクリーンショットや手入力で選手を登録し、編成判断に必要な資料を管理します。AIによる補強・ドラフト推薦は実装していません。

## 初めて使う

1. `index.html` を開いてアプリを確認できます。ただし、**iPhoneのファイルアプリからローカルHTMLを開く使い方は永続保存が安定しないため、継続利用には不向き**です。
2. **推奨**：フォルダ内の `index.html`、`manifest.webmanifest`、`sw.js`、アイコンファイルを同じ階層で GitHub Pages などの静的HTTPS公開サービスに配置します。
3. iPhoneのSafariで公開URLを開き、「共有」→「ホーム画面に追加」でアプリ風に使用できます。オフライン時に通常画面を表示できるよう基本画面をキャッシュしますが、OCR初回実行やOCR言語データ取得にはインターネット接続が必要です。
4. 初期の球団名は「広島シープ」、初期年度はゲーム画像に合わせて**2028年**にしています。設定から球団名を変更できます。選手名簿は**空欄**です。

## 機能一覧

| 画面 | 実装内容 |
|---|---|
| 編成分析 | 支配下の登録数／残り枠（既定70、変更可）、育成人数、退団予定、FA接近人数、平均年齢、ポジション別目安差、年齢帯別の薄さ |
| 中期見通し | 2・3・5年先の支配下／育成／年齢帯／FA残年数を予測値ではなく機械的に試算。保存済み年度は実記録を使用 |
| FA管理表 | 国内・海外FA残年数、到達予定年度の一覧。自動更新は毎年-1という仮定で手動修正可 |
| 適性マトリクス | 投手の先発・中継ぎ・抑え、野手各ポジション。D−以上だけ／すべての適性を切替 |
| 選手名鑑 | 名前、年度時点の年齢、国内・海外FA、入団年、今季・来季のプロ年数、背番号、支配下／育成、役割、守備力、年俸（任意）、メモ、状態 |
| 戦力構想 | 引退・戦力外・移籍／退団予定、加入予定、退団済を管理。仮の退団・加入を保存するシミュレーターと確定反映 |
| ドラフト | 指名年・支配下／育成・指名順位・氏名・指名時年齢・出身校・ポジション・**注目度／将来性**・メモ。選手名鑑と紐付けて現在の状態／年度別推移を確認 |
| 年度・設定 | 前年・翌年の保存、年度比較、年度ごとの編成メモ、目安人数、支配下枠上限、JSONバックアップ・復元 |
| 写真取り込み | 選手詳細画面／ドラフト指名結果の写真を複数枚選択→ブラウザ内OCR→編集可能な確認表→登録。写真のドラフト候補を一括で加入予定に登録する選択肢あり |

## 特に重要な取り扱い

- **育成選手は支配下の70人枠には含めません**。一軍・二軍と契約区分は別です。「葉っぱ」が画像で認識できない場合があるので、取り込み時に「育成」を指定してください。
- ポジションの**主力適性**はD−以上。D−以上が1つもなければ、登録した順序の先頭1つを主力として扱います。2ポジションがD−以上なら2ポジションに重複計上するため、ポジション人数の合計は実人数と一致しません。
- ゲーム内で「外野」としか表示されない場合、**左右・中堅に自動で振り分けず「外野（総合）」という独立ポジションで保存**します。必要なら名鑑から個別の右翼・中堅・左翼を追加してください。
- 投手の「先発・中継ぎ・抑え」の適性ランクと、編成上の起用方針（先発ローテ・ロングリリーフ等）は**別フィールド**です。
- ドラフトの「注目度」「将来性」は**指名時点の固定した記録**であり、現在の選手能力と混ぜません。選手名鑑のデータを削除してもドラフト指名記録は残ります。名鑑と紐付いていない指名者は、状態を「紐付けなし」と表示します。
- ドラフト指名結果の写真には、指名時の「注目度」「将来性」が載っていないことがあります。その場合は**不明**で登録し、指名者詳細画面をもとに後で追記してください。写真OCRは実際の「指名選手一覧」画面での精度検証が未完了です。
- 翌年度作成は**年齢+1、国内／海外FA残年数−1**（0を下回らない）の仮更新です。実際のゲーム内部処理と異なる場合は手動修正してください。
- 「来季構想」は「現在在籍+加入予定−退団予定」による表示で、**編成シミュレーターの仮操作は確定名簿には影響しません**。保存したシナリオも年度ごとに分離されます。
- 保存済み年度を編集しても、すでに作った後年のスナップショットには自動反映しません。前年が上書きされることもありません。

## 画像認識とプライバシー

OCRはTesseract.js v5.1.1と日本語・英語言語モデルをCDNから読み込み、**ブラウザ内で画像認識**します。画像をこのアプリ独自のサーバーには送信しません。CDNへの接続とOCRモデルのダウンロードが必要です。OCRはレイアウト・ランク・文字の誤読を起こすことがあるため、候補表で内容を必ず確認してください。

データはブラウザの `localStorage` に保存されます。クラウド同期はなく、Safariのサイトデータ消去、公開URLの変更、端末変更などで失われる可能性があります。**こまめに「全年度をJSONで保存」を利用し、iCloud Drive等にバックアップしてください。**

## 更新時のデータ互換性

旧版と同一URL・同一ブラウザで開いた場合、旧版の `bokupro-roster-v1` 形式を拡張して読み込む設計です。元からある選手情報・年度別名簿は残し、新項目には初期値を補います。サーバー公開場所が変わった場合は、旧版の「JSONで保存」→新版の「JSONを読み込む」で移行してください。新形式を古い版で読み込むことは推奨しません。

## 同梱ファイル

- `index.html` — メインアプリ・データ保存・画面表示・写真OCR・編成計算
- `manifest.webmanifest` — iPhoneホーム画面追加用の設定
- `sw.js` — 公開サイトの基本画面をキャッシュ
- `icon.svg`、`icon-180.png`、`icon-192.png`、`icon-512.png` — 非公式の独自アイコン
- `preview.png` — 開発時の画面プレビュー（サンプル数値ではありません）

## 検証済み／未検証

**操作テスト済み**：支配下・育成別人数、投手適性入力、国内・海外FAと入団年、ドラフトの注目度・将来性保存と選手連携、仮シナリオ保存、翌年度作成と旧年データ保持、年次比較、画面遷移。JavaScriptの構文検査も実施。

**実機未検証**：iPhone Safariでのホーム画面追加、Tesseractの実際の写真OCR精度、ドラフト結果画面からの正確な一括行解析。必要な情報が見つからなければ不明として保存し、誤認識は確認画面で修正してください。
